========================================
📞 فون کالز کیسے چالو کریں
========================================

✅ خوشخبری: آپ کا کوڈ پہلے سے تیار ہے!
✅ صرف Twilio سیٹ اپ کرنا ہے

========================================
ضروریات
========================================

1. Twilio اکاؤنٹ (فون سروس)
   قیمت: $15 مفت کریڈٹ
   فون نمبر: ~$1/ماہ
   ویب سائٹ: https://www.twilio.com/try-twilio

2. OpenAI API Key (ترجمہ کے لیے)
   قیمت: $5-10 کریڈٹ
   ویب سائٹ: https://platform.openai.com/signup

3. ngrok (لوکل سرور کھولنے کے لیے)
   قیمت: مفت
   ویب سائٹ: https://ngrok.com/download

========================================
فوری سیٹ اپ (15 منٹ)
========================================

قدم 1: Twilio اکاؤنٹ بنائیں
→ https://www.twilio.com/try-twilio پر جائیں
→ سائن اپ کریں
→ $15 مفت کریڈٹ ملے گا! ✅

قدم 2: فون نمبر خریدیں
→ Twilio Console میں: Phone Numbers → Buy
→ اپنا ملک منتخب کریں (Pakistan: +92)
→ کوئی بھی نمبر خریدیں (~$1)

قدم 3: Twilio Credentials کاپی کریں
→ Dashboard سے یہ کاپی کریں:
   - Account SID (AC سے شروع)
   - Auth Token
   - Phone Number (+1234567890)
→ محفوظ رکھیں!

قدم 4: OpenAI API Key حاصل کریں
→ https://platform.openai.com پر سائن اپ
→ $5-10 کریڈٹ ڈالیں
→ API key بنائیں (sk- سے شروع)
→ کاپی کر کے محفوظ رکھیں!

قدم 5: .env فائل اپ ڈیٹ کریں
→ فائل کھولیں: backend\.env
→ اپنی اصلی values ڈالیں:

TWILIO_ACCOUNT_SID=ACxxxxxxxxx
TWILIO_AUTH_TOKEN=your_token
TWILIO_PHONE_NUMBER=+1234567890
OPENAI_API_KEY=sk-xxxxxxxxx

قدم 6: ngrok انسٹال کریں
→ https://ngrok.com/download سے ڈاؤن لوڈ
→ Extract کریں

قدم 7: ngrok چالو کریں
→ نیا PowerShell کھولیں
→ چلائیں: ngrok.exe http 8000
→ HTTPS URL کاپی کریں (مثال: https://abc123.ngrok-free.app)

قدم 8: .env میں URL ڈالیں
→ backend\.env کھولیں
→ ڈالیں: SERVER_URL=https://abc123.ngrok-free.app

قدم 9: Backend دوبارہ شروع کریں
→ Backend بند کریں (Ctrl+C)
→ دوبارہ چالو کریں:
   cd backend
   python -m uvicorn app.main:app --reload

قدم 10: Twilio Webhook سیٹ کریں
→ Twilio Console: Phone Numbers → اپنا نمبر
→ Voice Configuration میں:
   - Webhook: https://your-ngrok-url.ngrok-free.app/voice/incoming
   - Method: POST
→ Save دبائیں

========================================
✅ مکمل! اب ٹیسٹ کریں
========================================

اپنے فون سے:
1. Twilio نمبر کال کریں
2. "Welcome to Voice Bridge" سنیں
3. زبان منتخب کریں (1=English, 2=Urdu, 3=Punjabi)
4. بات کریں!
5. ترجمہ سنیں!

========================================
کیسے کام کرتا ہے
========================================

آپ کا فون → Twilio → ngrok → Backend → ترجمہ → آواز

فوری ترجمہ فون کال کے دوران!
