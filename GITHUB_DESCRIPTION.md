## 📋 FULL DESCRIPTION (For README or About)

### English Version:

```markdown
# 🌍 VoiceBridge - Real-Time Voice Translation

Break language barriers with real-time voice translation between 15 languages!

## ✨ Features

- **15 Languages Supported:** English, Urdu, Punjabi, Arabic, Hindi, Chinese, Spanish, German, French, Japanese, Korean, Portuguese, Russian, Turkish, Italian
- **Voice Input/Output:** Speak naturally and hear translations
- **13 Common Phrases:** Instant translation for greetings and basic conversation
- **Web Interface:** Modern, user-friendly React application
- **Phone Call Support:** Twilio integration for real phone translations (optional)
- **Fallback Mode:** Manual text input when voice isn't available
- **Conversation History:** Track your translations in real-time

## 🚀 Quick Start

### Web Version (Works Immediately)
1. Clone the repository
2. Install dependencies: `npm install` (frontend) and `pip install -r requirements.txt` (backend)
3. Start frontend: `npm run dev`
4. Start backend: `uvicorn app.main:app --reload`
5. Open http://localhost:5173

No API keys required for basic 13 phrases!

### Full Translation (Optional)
- Add OpenAI API key to `backend/.env`
- Translates any custom sentence

### Phone Calls (Optional)
- Setup Twilio account
- Configure webhook in `.env`
- Call from real phones with real-time translation

## 🛠️ Tech Stack

- **Frontend:** React, Vite, Web Speech API
- **Backend:** FastAPI, Python
- **Translation:** OpenAI GPT-4 (optional), Built-in dictionary
- **Voice:** Browser TTS/STT, Twilio (optional)
- **Languages:** 15 languages with native script support
```
