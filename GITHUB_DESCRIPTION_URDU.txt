🌍 VoiceBridge - فوری آواز ترجمہ

15 زبانوں میں فوری ترجمے کے ساتھ زبان کی رکاوٹوں کو توڑیں!

✨ خصوصیات

• 15 زبانیں: انگریزی، اردو، پنجابی، عربی، ہندی، چینی، ہسپانوی، 
  جرمن، فرانسیسی، جاپانی، کورین، پرتگالی، روسی، ترکی، اطالوی

• آواز ان پٹ/آؤٹ پٹ: قدرتی طور پر بولیں اور ترجمہ سنیں

• 13 عام جملے: فوری ترجمہ روزمرہ کی بات چیت کے لیے

• ویب انٹرفیس: جدید، استعمال میں آسان React application

• فون کال سپورٹ: Twilio کے ذریعے حقیقی فون ترجمے

• فال بیک موڈ: دستی ٹیکسٹ ان پٹ جب آواز دستیاب نہ ہو

• گفتگو کی تاریخ: اپنے ترجموں کو ٹریک کریں

🚀 فوری شروعات

1. Repository clone کریں
2. Dependencies انسٹال کریں
3. Frontend: npm run dev
4. Backend: uvicorn app.main:app --reload
5. http://localhost:5173 کھولیں

بنیادی 13 جملوں کے لیے API keys کی ضرورت نہیں!

🛠️ ٹیکنالوجی

• Frontend: React, Vite, Web Speech API
• Backend: FastAPI, Python
• ترجمہ: OpenAI GPT-4 (اختیاری), Built-in dictionary
• آواز: Browser TTS/STT, Twilio

📖 دستاویزات

• USER_GUIDE_URDU.txt - اردو میں مکمل گائیڈ
• TESTING_GUIDE.md - کیسے ٹیسٹ کریں
• PHONE_SETUP_GUIDE.md - فون کالز کیسے چالو کریں

• API keys source code میں نہیں
