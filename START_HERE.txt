HOW TO USE (USER GUIDE)
==================================================

STEP 1: OPEN WEBSITE
→ Go to: http://localhost:5173
→ You will see VoiceBridge interface

STEP 2: SELECT LANGUAGES
→ "I speak" = Your language (example: Urdu)
→ "They hear" = Other person's language (example: Chinese)

STEP 3: START TALKING
→ Click GREEN microphone button
→ Browser will ask "Allow microphone" → Click ALLOW
→ Speak clearly in your language
→ System will translate and speak in other language!

IF MICROPHONE ERROR (Network error)
==================================================

SOLUTION 1: TYPE MANUALLY
→ When error appears, text box will show
→ Type your message
→ Press Enter
→ Translation will work same as voice!

SOLUTION 2: CHECK INTERNET
→ Speech recognition needs internet
→ Make sure WiFi connected

SOLUTION 3: USE CHROME BROWSER
→ Chrome works best
→ Download: https://www.google.com/chrome/
