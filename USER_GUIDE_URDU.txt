==================================================
استعمال کرنے کا طریقہ
==================================================

قدم 1: ویب سائٹ کھولیں
→ یہ لنک کھولیں: http://localhost:5173
→ VoiceBridge انٹرفیس نظر آئے گا

قدم 2: زبانیں منتخب کریں
→ "I speak" = آپ کی زبان (مثال: اردو)
→ "They hear" = دوسرے کی زبان (مثال: چینی)

قدم 3: بات کریں
→ سبز مائیکروفون بٹن دبائیں
→ براؤزر پوچھے گا "Allow microphone" → ALLOW دبائیں
→ اپنی زبان میں صاف بولیں
→ سسٹم ترجمہ کرے گا اور دوسری زبان میں بولے گا!

اگر مائیکروفون میں خرابی (Network error)
==================================================

حل 1: دستی طور پر ٹائپ کریں
→ جب خرابی آئے، ٹیکسٹ باکس نظر آئے گا
→ اپنا پیغام ٹائپ کریں
→ Enter دبائیں
→ ترجمہ آواز جیسا ہی کام کرے گا!

حل 2: انٹرنیٹ چیک کریں
→ تقریر کی شناخت کو انٹرنیٹ چاہیے
→ یقینی بنائیں WiFi جڑا ہوا ہے

حل 3: Chrome براؤزر استعمال کریں
→ Chrome سب سے بہتر کام کرتا ہے
→ ڈاؤن لوڈ: https://www.google.com/chrome/

استعمال کی مثال
==================================================

منظر نامہ: پاکستانی (اردو) چینی شخص سے بات کر رہا ہے

شخص A (پاکستانی):
→ کھولیں: http://localhost:5173
→ منتخب کریں: I speak = Urdu, They hear = Chinese
→ مائیک دبائیں، کہیں: "السلام علیکم"
→ چینی شخص سنے گا: "你好" (چینی آواز میں)

شخص B (چینی):
→ کھولیں: http://localhost:5173
→ منتخب کریں: I speak = Chinese, They hear = Urdu
→ مائیک دبائیں، کہیں: "谢谢"
→ پاکستانی شخص سنے گا: "شکریہ" (اردو آواز میں)

✅ دونوں بات چیت کر سکتے ہیں!

دوسروں کے ساتھ شیئر کریں
==================================================

دوسروں کو استعمال کرنے دینے کے لیے:

طریقہ 1: مقامی نیٹ ورک
→ اپنا IP تلاش کریں: ipconfig
→ شیئر کریں: http://YOUR-IP:5173
→ ایک ہی WiFi پر کام کرتا ہے

طریقہ 2: انٹرنیٹ (سیٹ اپ چاہیے)
→ ngrok استعمال کریں یا cloud پر deploy کریں
→ PHONE_SETUP_GUIDE.md دیکھیں
